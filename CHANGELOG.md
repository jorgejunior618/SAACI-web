# Changelog

As mudanças de cada versão estão nas
[Releases do GitHub](https://github.com/jorgejunior618/SAACI-web/releases). Cada release traz a tag
`vX.Y.Z` e as notas geradas a partir dos PRs mergeados.

O projeto segue o [Versionamento Semântico](https://semver.org/lang/pt-BR/). A versão é calculada
pelos [Conventional Commits](https://www.conventionalcommits.org/pt-br/): `feat` sobe o minor, `fix`
e `perf` sobem o patch, e breaking change sobe o major (o minor enquanto a versão for 0.x). Detalhes
na [ADR 0022](doc/adr/0022-versionamento-e-releases.md).
